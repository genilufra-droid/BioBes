# Contributing

Përdor branch develop për punë të reja dhe main për release. Commit-et përdorin Conventional Commits si feat, fix, docs dhe chore. Çdo pull request shpjegon company scope, migration impact, testet dhe ndikimin te raportet. Ekzekuto pnpm check && pnpm test && pnpm build para review. Mos commit-o secrets, të dhëna reale, build artifacts ose modulin Pagat.
