# Shtimi i një raporti

Regjistro raportin në shared/reportCatalog.ts, ndërto query-n me companyId dhe filtrat në router, krijo view në client/src/pages ose komponentin e modulit dhe përdor eksportuesit ekzistues PDF/Excel. Ruaj të njëjtat kolona në web dhe dokument, testo filtrat e kombinuar, totalet dhe rastin bosh. Për linke burimi përdor SourceDocumentLink.
