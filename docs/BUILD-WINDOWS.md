# Build Windows

Wrapper-i është te desktop/ dhe përdor Electron me context isolation. Në Windows ekzekuto cd desktop, pnpm install dhe pnpm start. Për installer ekzekuto pnpm build:windows; output-i del te desktop/release/. Target-i mund të jetë BIOBES_URL ose server lokal http://localhost:3000. Offline i plotë kërkon database/server lokal.
