# Shtimi i një moduli

Përcakto entitetet dhe company scope në schema, krijo migration SQL, shto helper-at në server/db.ts, procedurat tRPC me Zod, page/components në client/src, menu/link dhe permission. Shto formularin, validimet, raportin dhe teste Vitest. Ekzekuto pnpm check, pnpm test dhe pnpm build. Çdo mutation duhet të verifikojë companyId.
