# Shtimi ose ndryshimi i formularit

Përcakto input schema me Zod, required fields, default-et dhe validimin business. Në React përdor controlled selects për të dhënat asinkrone, requestSubmit për toolbar dhe tRPC mutation për ruajtje. Kontrollo artikuj realë, sasi pozitive, magazinë dhe company scope. Shto test regresioni dhe verifiko desktop/mobile.
